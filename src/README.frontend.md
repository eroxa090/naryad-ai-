# Фронтенд НарядAI

Рабочая ветка: `frontend`. Общие типы импортируются из `shared/types.ts`; зависимости и чужие зоны не изменены.

## Локальный запуск

`npm install`, затем `npm run dev`. В `.env` нужны предоставленные командой `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` и `AI_MOCK=true`. `.env` не коммитится.

`AI_MOCK` передаётся Vite в браузер только как булев флаг. После изменения перезапустите dev-сервер или пересоберите приложение. При `false` все ИИ-запросы идут на `/api/ai/*` с JWT. Для локальных серверных функций используйте командный `npm run dev:full`: локальный Vite проксирует `/api` на `https://naryadai-kz.vercel.app` (changeOrigin: true). Ошибка уведомления не отменяет созданный наряд и не запускает повторное создание.

## Демо

1. Войти как `master1` (ПИН из инструкции команды), создать наряд, выбрать исполнителя `worker1`.
2. Войти как `worker1`, принять, начать, заполнить работы и шифр, добавить материалы и фото, отправить отчёт.
3. Войти как `master1`, проверить карточку, закрыть наряд. Для реальных сохранённых ИИ-оценок доступно изменение оценки через `master_override_review`.
4. Войти как `manager1`, открыть отчёты, экспортировать PDF/Excel и проверить ИИ-ассистента.

ИИ-моки явно отмечены. Мок проверки не записывает вымышленную оценку в `ai_reviews`; мастер может вызвать его кнопкой «Проверить ИИ». Реальную оценку сохраняет серверный `check-order`. Распознавание в режиме моков возвращает пример текста, а не содержимое записи.

## Офлайн и PWA

После первого входа данные пользователя и просмотренные карточки кэшируются в Dexie. Статусы и отчёты с фото сохраняются в очередь отдельно для каждого пользователя; отправка последовательная при восстановлении сети. Ошибка останавливает очередь и показывает действия повтора/удаления. Статус не показывается как изменённый до подтверждения сервера. Если сервер применил RPC, но соединение пропало до ответа, повтор может потребовать ручного разрешения конфликта: серверный контракт не предоставляет ключ идемпотентности.

PWA проверяется через `npm run build` и `npm run preview`. Для телефона нужны HTTPS, разрешения камеры и микрофона. Кнопка установки появляется, когда браузер выдаёт `beforeinstallprompt`; также доступно меню браузера «Установить приложение». Обновление service worker не перезагружает активную форму автоматически.

## Метрики

Панель использует смены 08:00–20:00 / 20:00–08:00 по времени устройства; границы явно показаны. Это фронтендное допущение, поскольку календаря смен в контракте нет. Отчёты фильтруют наряды по дате создания. Рейтинг — представление за 30 дней, рейтинг бригады — среднее её исполнителей с оценкой. Простой — подписанная оценка суммарных часов аварийных работ, а не измерение физических остановок оборудования.

Карта здоровья читает `ai_insights`, `kind=equipment_risk`, ожидает `data.equipment_id` и числовой `data.risk` в диапазоне 0–1. Пока аналитика не записала данные, оборудование серое («Нет оценки»). Идентификатор оборудования внутри JSON нужно согласовать с Человеком 3, если его реализация использует другой ключ.

## Проверка

Обязательные команды: `npm run typecheck` и `npm run build`. Дополнительно `npm run lint`.

7 октября 2026 проверено в Chromium с реальным Supabase:

- все четыре тестовых аккаунта;
- сквозной наряд №613: создание → принятие → начало → исполнение → закрытие;
- аварийный №614: запрет отчёта без фото, офлайн-очередь, повторная отправка при появлении сети, ровно одно JPEG-фото 512×512 в Storage;
- №615: Realtime-баннер и появление наряда без перезагрузки; тестовый наряд отменён;
- офлайн-перезагрузка production PWA после первоначальной загрузки;
- мобильная ширина 390px: нет переполнения страницы, проверенные кнопки не ниже 56px;
- скачивание PDF и Excel.

Камера, физический микрофон, установка на реальном Android и реальные ИИ-ответы требуют проверки на устройстве / развёрнутом API.


## Обновление фронтенда

Первичная загрузка содержит активные наряды и закрытые за последние 30 дней (по closed_at). Полная история загружается при открытии Reports. Прямые ссылки на старые карточки загружают один наряд отдельно.

Оборудование → «Печать QR» открывает сетку карточек для A4. Кодируется equipment.qr_code без изменения значения. В шапке доступен блок Telegram с командой `/start <логин> <ПИН>`. Переключатель RU/KZ сохраняет язык; вход и рабочий сценарий переведены через i18next (код казахского языка kk). Данные справочников и серверные тексты не переводятся автоматически.
